重点更新

3D 分镜先把镜头说清楚。

统一 SceneBoard

集中管理角色、道具、姿态、摄影机、焦距、关键帧、运动轨迹和时间线预演。

3D 交互修复

单个模型和组合道具都能可靠旋转并保存；左键平移、Shift + 左键 环绕，右键只打开场景菜单。

移动端镜头捕捉

Android 技术预览支持陀螺仪 / 双摇杆运镜、3D 场景编辑和关键帧动画。真实设备硬件验收仍在进行；iOS 上线时间未定。

安装说明

系统可能提示未验证开发者。

macOS

安装包为 ad-hoc 签名，未经过 Apple notarization。首次打开请右键 App 选择「打开」；仍被拦截时按 Manual 的 Gatekeeper 路径处理。

Windows

安装包未签名。SmartScreen 出现时先确认文件名来自本页，再点「更多信息」与「仍要运行」。本版尚未完成真实 Windows 机器上的安装启动验收。
