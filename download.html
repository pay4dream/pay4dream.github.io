1.1.2 重点更新

第五工作区，让静态 KV 和动态参考留在同一张卡片。

KV 创作 · 第五工作区

与图片生成、3D 分镜、视频生成、剪辑并列。组合角色、场景、构图和风格参考，完成完整静态 KV，不再把主视觉拆成零散素材。

一键动态 KV

选中已生成的静态 KV，一键把它作为首帧生成短动态参考。提交前确认内容与费用，未知结果不自动重投，静态原图与动态结果保留在同一张卡片。

Agent CLI 与桌面 Agent API

安装包内提供服务同版本的 p4d-cli 与 p4d 别名。Agent 只连接本机正在运行的桌面会话，执行已注册命令；付费、破坏性和敏感操作仍需明确确认。

3D 构图与制作链

3D 分镜机位可带入 KV 参考；同时改进项目切换、Canvas 节点操作、剪辑恢复与工程文件展示。Public 版不提供骨骼姿态或关节手柄编辑。

安装说明

系统可能提示未验证开发者。

macOS

1.1.2 安装包为 ad-hoc 签名，尚未经过 Apple 公证（notarization）。先核对本页文件名与 SHA256；确认来源后可右键 App 选择「打开」，仍被拦截请查阅试用指南。不要关闭系统安全保护。

Windows

1.1.2 安装包未签名，且本版尚未完成真实 Windows 机器上的安装启动验收。SmartScreen 出现时先核对文件名与 SHA256，确认来源后再决定是否继续安装，并保留原项目备份。

开始前准备

无需邀请码；模型服务由你自行配置。

模型服务需由你自行配置并确认可用额度；付费生成前须确认内容与费用。连接远端服务时，生成所需内容会发送给对应服务。Agent 只连接本机桌面会话，可视化与 KV 草稿仍留在软件端。

本次不包含新的移动端版本。历史带水印素材不会自动变成无水印原片。
