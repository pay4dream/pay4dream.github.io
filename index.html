为什么需要它

五个工作区，接住同一套创作上下文。

Pay4Dream 用一个本地工作台承接图片生成、3D 分镜、KV 创作、视频生成与剪辑。参考、镜头、任务、结果和导出记录都留在同一个项目里，可以反复修改和继续制作，不再散落在多个网页、聊天记录和文件夹里。

工作方式

图片、3D 分镜、KV、视频与剪辑，五个工作区并列。

01

图片生成

生成、编辑通用图片与角色、场景素材，结果直接进入项目资产库，继续供下游镜头和 KV 使用。

02

3D 分镜

在 SceneBoard 里摆放角色占位、场景与摄影机，先确认构图、动作和运镜，再把机位带入 KV 或视频生成。

03

KV 创作 · 第五工作区

组合角色、场景、构图与风格参考，得到完整静态 KV；已生成图像可一键转为动态 KV，并保留原图、任务上下文和改稿链。

04

视频生成

按镜头意图生成视频候选，结果先预览、再明确采用，继续进入剪辑；已有任务可查询、下载或导入恢复。

05

剪辑

把图片、动态 KV 与视频片段组织成片，调整时长与配音，预览后导出，并保留项目内可继续修改的制作记录。

3D 分镜 · 历史界面示意

先在 3D 分镜里把镜头走一遍。

角色、道具、摄影机、运动轨迹和时间线在同一个 SceneBoard 里汇合。先确认构图、动作和运镜，再把导演意图带入视频生成。

适合的团队

给需要持续产出视频的人，而不是只做一次性尝试的人。

内容团队

把选题、脚本、素材生成和剪辑输出放在同一个项目中，减少跨工具搬运。

产品和营销

快速把功能卖点、活动物料、文档资料和讲解脚本做成可预览的视频版本。

独立创作者

使用自己的模型账号，项目和素材留在本机，创作节奏由你自己掌控。

第五工作区：KV 创作

与图片生成、3D 分镜、视频生成、剪辑并列。面向完整主视觉参考，不再把 KV 拆成图库里的单张素材或另一套独立项目。

完整静态 KV

角色、场景、构图与风格参考各有用途，可选外部参考、自动构图或 3D 分镜机位。上一稿的参考可继续复用，再逐步换人、换景或换构图。

一键动态 KV

选中已生成的静态 KV，一键把它作为首帧生成短动态参考。提交前显示内容与费用确认，未知结果不自动重投，静态原图和动态结果留在同一张卡片。

Agent CLI 与桌面 Agent API

安装包内提供服务同版本的 p4d-cli 与 p4d 别名。Agent 只连接本机正在运行的桌面会话，执行已注册命令；付费、破坏性和敏感操作仍需明确确认。

3D 构图衔接

把 3D 分镜里的机位与构图带入 KV 创作，在静态与动态参考之间反复比较。Public 版仍使用程序化角色占位，不提供骨骼姿态或关节手柄编辑。

制作链稳定性

改进项目切换、Canvas 节点操作、剪辑恢复与工程文件展示。历史带水印素材不会自动变成无水印原片。

项目上下文

生成结果留在项目里，而不是散落在聊天记录里。

图片、3D 构图、KV 与视频结果都落回项目资产和任务状态，方便继续挑选、替换、反馈和剪辑。SceneBoard、参考素材与 KV 改稿链会随项目继续带入下游制作。
